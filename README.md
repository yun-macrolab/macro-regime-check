# macro-regime-check

미국 공개 통계(FRED) 22개 시리즈를 받아 코드로 공개된 **규칙 11개**가 충족됐는지 판정하고, 미국 영업일 다음 날 아침(KST 화~토 07:17)마다 자동으로 갱신하는 점검 페이지입니다.

**[점검 페이지 보기](https://yun-macrolab.github.io/macro-regime-check/)** · 투자 판단이나 권유가 아니라, 공개된 규칙을 공개 통계에 적용한 출력입니다.

| 구분 | 내용 |
|---|---|
| 하는 것 | FRED 원자료 수신(API 키 없이 공개 CSV) → 전년비·3개월 변화·60영업일 상관 등 계산 → 규칙별 충족 / 미충족 / 판정 불가 → 공개본·그래프 자료·상태 기록 → 페이지 배포 |
| 싣지 않는 것 | 제 시장 견해(듀레이션·커브 판정과 점수), 재배포가 제한된 지수(S&P·ICE·Moody's 계열 4개)의 값 — 규칙 충족 여부와 자료 상태만 보여 주고, S&P500은 원값을 되살릴 수 없는 60영업일 상관과 연속 일수만 계산값으로 싣습니다 |
| 하지 않는 것 | 매매 신호·수익률 전망, 규칙의 적중률 평가(아직 검증 전) |

22개 중 원/달러·M2 유통속도·IG 스프레드 3개는 규칙에 쓰지 않고 자료 상태만 보여 줍니다.

## 규칙 11개

| 신호 | 충족 조건 |
|---|---|
| 기업대출 증가율 대 명목 성장률 | C&I 대출 전년비가 명목GDP 전년비보다 낮으면 |
| 은행의 비은행 금융기관 대출 | 전년비(재분류로 보이는 주간 +40십억달러 이상 증가 계단 제외)가 10% 미만이면 |
| 신용 스프레드 | Baa−10년 스프레드가 12개월 저점보다 0.4%p 이상 넓어지거나 HY OAS가 4.61%p를 넘으면 |
| 주가-금리 60영업일 상관 | S&P500 일간 수익률과 미 10년 금리 일간 변화의 60영업일 상관이 126영업일 이상 계속 양(+)이면 |
| 10년−2년 금리차 | 0보다 작으면 |
| 실질금리와 기대인플레이션 | 10년 실질금리가 2% 미만이고 10년 BEI가 3개월 전보다 높으면 |
| 근원 물가 | 근원 PCE 전년비가 3% 이하이면 (근원 CPI는 참고) |
| 10년 기간 프리미엄 | Kim-Wright 10년 기간 프리미엄이 3개월 전보다 0.25%p 이상 낮아지면 |
| 단기 조달금리 SOFR | 3개월 전보다 0.25%p 이상 높아지면 |
| 지준과 통화승수 | 지준/명목GDP가 9% 미만이거나, 3개월 새 0.3%p 이상 늘고 근원 PCE 전년비가 2%를 넘으면 |
| 미 증권·투자업 고용 | 고용 전년비가 0보다 작으면 |

판정 로직과 임계값은 [`scripts/regime_rules.py`](scripts/regime_rules.py)의 표(`TH`)에서, 페이지에 싣는 규칙 문장은 [`scripts/render_public.py`](scripts/render_public.py)의 `public_rules()`에서 나옵니다(문장 속 임계값도 `TH`에서 읽습니다). 판정 코드 원문에는 원본 파이프라인의 시나리오 구분 문구가 남아 있지만, 페이지와 공개본에는 싣지 않습니다. 계산 규칙 몇 가지:

- **월간·분기 전년비는 1년 전 같은 달이 있을 때만** 계산합니다. 결측월을 전 달 값으로 메우지 않습니다.
- **복합 조건은 3값 논리**로 판정합니다. 한쪽 자료가 없어도 결론이 나는 경우만 충족·미충족으로 쓰고, 나머지는 '판정 불가'로 둡니다.
- 임계값과 비교하기 전에 계산값을 소수 여섯째 자리까지 반올림합니다(0.40이 0.3999…로 계산돼 경계를 놓치지 않게).

## 동작 방식

GitHub Actions가 예약 시각마다 돕니다([`daily.yml`](.github/workflows/daily.yml)).

1. **검사** — 공개 전 검사와 단위 테스트
2. **갱신** — 수집·판정 → 공개본(`data/public.json`) → 그래프 자료(`data/charts.json`) → 상태 기록(`data/status.json`) → 새 산출물 포함 공개 전 검사 → 봇 커밋
3. **배포** — `site/`와 `data/`만 GitHub Pages로
4. **알림** — 갱신이나 그래프 자료 생성이 실패하면 실행을 실패로 끝냅니다

실패한 날에는 직전 공개본이 그대로 남고, 페이지 첫 화면에 실패 배너와 마지막 성공 시각이 나옵니다. 그래프 자료만 실패한 날에는 직전 그래프가 남고 "그래프는 그 날짜 기준"이라고 표시합니다. 예정된 실행이 아예 빠진 경우에도 배너를 띄웁니다. 수신에 실패한 시리즈가 3개 이상이면(캐시로 대신한 것 포함) 그날은 기록하지 않습니다 — 오래된 캐시를 오늘 결과로 내보내지 않기 위해서입니다.

## 그래프

페이지 위쪽 **금리 한눈에 보기**(최근 5년, 주간)와 **규칙 카드마다 작은 추이**(최근 3년)를 그립니다.

| 그래프 | 그리는 것 |
|---|---|
| 미 10년 금리 분해 | 명목 10년 · 10년 실질 · 10년 BEI |
| 기간 프리미엄과 10년−2년 | Kim-Wright 10년 기간 프리미엄 · 10년−2년 |
| 규칙 카드 9개 | 그 규칙이 실제로 비교하는 양과 임계값 점선 (예: NDFI 전년비와 10%, 기간 프리미엄 3개월 변화와 −0.25%p) |

- **카드 값과 같은 계산입니다.** [`scripts/render_charts.py`](scripts/render_charts.py)가 표본 날짜마다 원자료를 그 날까지 자르고 규칙 점검과 같은 함수로 계산하므로, 그래프의 마지막 점이 카드에 적힌 값과 같습니다(테스트가 강제).
- 신용 스프레드 카드는 재배포 제한 자료라 그래프가 없습니다. SOFR 그래프는 뉴욕 연은 고지 문구를 확인한 뒤 넣을 예정입니다.
- 페이지는 외부 라이브러리 없이 [`site/charts.js`](site/charts.js)로 그립니다. 마우스·손가락·키보드(←/→)로 날짜별 값을 보고, "표로 보기"로 모든 값을 표로 볼 수 있습니다.

## 공개 범위와 안전장치

- **원자료와 공개본을 나눴습니다.** 원자료 캐시와 원본 계산 결과는 커밋·배포하지 않는 작업 폴더에만 두고, 공개본은 허용 목록에 있는 값만 옮겨 만듭니다. 공개 문구를 정해 두지 않은 새 규칙이 원본에 생기면 공개본 만들기가 실패합니다.
- **공개 전 검사**([`scripts/check_blind.py`](scripts/check_blind.py)) — 개인정보·로컬 경로·토큰 같은 검사어가 작업 트리와 **과거 커밋 전체**(지운 파일, 커밋 작성자 정보 포함)에 하나라도 있으면 멈춥니다. 검사어 목록 자체는 공개하지 않고(로컬 파일·GitHub Secret), 인코딩을 바꾼 우회(전각 문자, HTML·JSON 이스케이프, CP949·UTF-16)도 찾습니다. 읽을 수 없는 파일은 통과시키지 않습니다.
  - push 전 로컬 훅(`.githooks/pre-push`, `git config core.hooksPath .githooks`로 켬)에서 걸리면 push가 멈춥니다.
  - GitHub Actions에서는 매 실행 처음과 봇 커밋 직전에 돌고, 걸리면 봇 커밋과 페이지 배포를 멈춥니다(이 검사는 push된 뒤에 돕니다).
- **그래프 자료도 같은 허용 목록으로** 만듭니다. 재배포가 제한된 지수의 원값은 어느 날짜 것도 싣지 않고(S&P500은 원값을 되살릴 수 없는 60영업일 상관만), 문구는 코드에 정해 둔 것만 나갑니다.
- **출처 표기** — FRED(Federal Reserve Bank of St. Louis), SOFR은 New York Fed. 페이지에는 시리즈별 FRED 링크·마지막 관측일·오래된 자료 표시를, 공개본(`data/public.json`)에는 시리즈별 출처 문구까지 싣습니다.

**테스트 153개 통과**(공개 전 검사 52 · 판정 48 · 공개본 16 · 상태 기록 12 · 그래프 25, 네트워크 불필요, Python 3.13 표준 라이브러리만 — 공개 전 검사와 그 테스트는 git 명령이 필요합니다).

- 공개 전 검사는 보호 장치를 하나씩 꺼 본 변이 검사 27건을 테스트가 모두 잡는 것까지 확인했습니다(변이 검사 스크립트는 저장소에 넣지 않았습니다).
- 여러 AI 검토자에게 서로 다른 관점으로 결함을 찾게 하고, **다른 검토자가 재현한 것만** 고쳤습니다.
- 첫 공개 실행(2026-09-27, 수동 실행)에서 GitHub 서버가 FRED 22개 시리즈를 모두 받아 판정·배포까지 마쳤습니다.

구현한 동작을 확인하는 검사이며, 규칙이 시장을 잘 맞히는지를 잰 것은 아닙니다.

## 한계

- **임계값은 추정치입니다.** 대부분은 개인 조사 보고서의 추정 수치이고, 기간 프리미엄·SOFR의 0.25%p와 지준 재확대 조건(3개월 +0.3%p, 근원 PCE 2%)은 보고서에 수치가 없어 구현 때 정한 제안값입니다. 어느 쪽도 적중률로 검증한 기준이 아닙니다. 규칙은 첫 실행 직전까지 다듬었고(판정 경계·3값 논리·계단 제외), 바뀐 내용은 커밋 기록에 남아 있습니다.
- **발표 시차** — GDP 같은 분기·월간 지표는 수 주에서 수 개월 늦게 반영됩니다. 페이지의 자료 기준일을 함께 봐야 합니다.
- **개정치** — FRED 값은 나중에 고쳐집니다. 과거 날짜를 다시 계산한 결과는 작업 폴더(비공개)에만 남기고, 공개본(`data/public.json`)과 `data/history/`는 되돌리지 않습니다.
- **결측** — 근원 CPI는 2025-10이 비어 있어, 그 달이 기준이 되는 12개월 뒤 전년비는 '산출 불가'로 둡니다.
- GitHub Actions 예약 실행은 수십 분 늦을 수 있습니다.

## 누가 무엇을 했나

| 부분 | 담당 |
|---|---|
| 무엇을 점검할지(신호 11개 채택), 공개 범위(제 판정·제한 지수 값을 싣지 않기), 검사어, 검증 기준, 결과 검수 | 직접 |
| 신호·임계값의 근거 자료 — AI 리서치 도구와 함께 쓴 개인 조사 보고서(임계값은 그 보고서의 추정치와 구현 때 정한 제안값) | 직접 + AI |
| 수집·판정·공개본·상태 기록 코드, 공개 전 검사, 워크플로·페이지·그래프(2026-09-29), 테스트 | Claude Code로 작성 |
| 결함 검토 — 관점을 나눈 여러 AI 검토자, 재현된 것만 반영 | Claude Code |
| 문서 정리(2026-09-29) | Claude Code로 작성 |

AI가 쓴 코드는 제가 규칙과 검증 기준을 정하고 결과를 검수하는 방식으로 썼습니다. 코드 커밋마다(봇의 자동 갱신 커밋 제외) AI 공동 작성 표시가 남아 있습니다.

## 직접 돌려 보기

```sh
python -X utf8 scripts/regime_check.py                      # FRED 수신·판정 → .work/ (원자료·원본 결과, 커밋하지 않음)
python -X utf8 scripts/render_public.py --out .work/public  # .work/ → 공개본 (기본값 data/는 저장소 파일을 덮어씀)
python -X utf8 scripts/render_charts.py --out .work/public  # .work/ → 그래프 자료 charts.json
```

API 키가 필요 없습니다. `--offline`을 붙이면 받아 둔 캐시만 씁니다. 공개 전 검사(`scripts/check_blind.py`)는 검사어 목록이 있어야 돌아가며, 목록은 공개하지 않습니다.
