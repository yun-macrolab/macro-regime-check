# macro-regime-check

미국 공개 통계(FRED) 22개 시리즈를 받아 코드로 공개된 **규칙 11개**가 충족됐는지 판정하고, 미국 영업일 다음 날 아침(KST 화~토 07:17)마다 자동으로 갱신하는 점검 페이지입니다.

**[점검 페이지 보기](https://yun-macrolab.github.io/macro-regime-check/)** · 투자 판단이나 권유가 아니라, 공개된 규칙을 공개 통계에 적용한 출력입니다.

| 구분 | 내용 |
|---|---|
| 하는 것 | FRED 원자료 수신(API 키 없이 공개 CSV) → 전년비·3개월 변화·60영업일 상관 등 계산 → 규칙별 충족 / 미충족 / 판정 불가 → 공개본·그래프 자료·상태 기록 → 페이지 배포 |
| 싣지 않는 것 | 제 시장 견해(듀레이션·커브 판정과 점수), 재배포가 제한된 지수(S&P·ICE·Moody's 계열 4개)의 값 — 규칙 충족 여부와 자료 상태만 보여 주고, S&P500은 원값을 되살릴 수 없는 60영업일 상관과 연속 일수만 계산값으로 싣습니다 |
| 하지 않는 것 | 매매 신호·수익률 전망, 규칙의 적중률 평가(아직 검증 전) |
| 참고로 싣는 것 | 한국 국고채 금리(3·5·10·30년) — **공개 통계가 아니라** 증권사 리서치팀 텔레그램 공개 채널 글에서 옮긴 숫자이고, 규칙 판정에는 쓰지 않습니다([아래](#참고-한국-국고채-금리)) |

22개 중 원/달러·M2 유통속도·IG 스프레드 3개는 규칙에 쓰지 않고 자료 상태만 보여 줍니다.

## 규칙 11개

| 신호 | 충족 조건 |
|---|---|
| 기업대출 증가율 대 명목 성장률 | C&I 대출 전년비가 명목GDP 전년비보다 낮으면 |
| 은행의 비은행 금융기관 대출 | 전년비(재분류로 보이는 주간 +40십억달러 이상 증가 계단 제외)가 10% 미만이면 |
| 신용 스프레드 | Baa−10년 스프레드가 12개월 저점보다 0.4%p 이상 넓어지거나 HY OAS가 4.61%p를 넘으면 |
| 주가-금리 60영업일 상관 | S&P500 일간 수익률과 미 10년 금리 일간 변화의 60영업일 상관이 126영업일 이상 계속 양(+)이면 |
| 10년−2년 금리차 | 0보다 작으면 |
| 실질금리와 기대인플레이션 | 10년 실질금리가 2% 미만이고 10년 BEI가 3개월 전보다 높으면 |
| 근원 물가 | 근원 PCE 전년비가 3% 이하이면 (근원 CPI는 참고) |
| 10년 기간 프리미엄 | Kim-Wright 10년 기간 프리미엄이 3개월 전보다 0.25%p 이상 낮아지면 |
| 단기 조달금리 SOFR | 3개월 전보다 0.25%p 이상 높아지면 |
| 지준과 통화승수 | 지준/명목GDP가 9% 미만이거나, 3개월 새 0.3%p 이상 늘고 근원 PCE 전년비가 2%를 넘으면 |
| 미 증권·투자업 고용 | 고용 전년비가 0보다 작으면 |

판정 로직과 임계값은 [`scripts/regime_rules.py`](scripts/regime_rules.py)의 표(`TH`)에서, 페이지에 싣는 규칙 문장은 [`scripts/render_public.py`](scripts/render_public.py)의 `public_rules()`에서 나옵니다(문장 속 임계값도 `TH`에서 읽습니다). 판정 코드 원문에는 원본 파이프라인의 시나리오 구분 문구가 남아 있지만, 페이지와 공개본에는 싣지 않습니다. 계산 규칙 몇 가지:

- **월간·분기 전년비는 1년 전 같은 달이 있을 때만** 계산합니다. 결측월을 전 달 값으로 메우지 않습니다.
- **복합 조건은 3값 논리**로 판정합니다. 한쪽 자료가 없어도 결론이 나는 경우만 충족·미충족으로 쓰고, 나머지는 '판정 불가'로 둡니다.
- 임계값과 비교하기 전에 계산값을 소수 여섯째 자리까지 반올림합니다(0.40이 0.3999…로 계산돼 경계를 놓치지 않게).

## 동작 방식

GitHub Actions가 예약 시각마다 돕니다([`daily.yml`](.github/workflows/daily.yml)).

1. **검사** — 공개 전 검사와 단위 테스트
2. **갱신** — 수집·판정 → 공개본(`data/public.json`) → 그래프 자료(`data/charts.json`) → 국고채 참고 자료(`data/ktb.json`) → 한국 시장(`data/korea.json`) → 상태 기록(`data/status.json`) → 새 산출물 포함 공개 전 검사 → 봇 커밋
3. **배포** — `site/`와 `data/`만 GitHub Pages로
4. **알림** — 갱신, 그래프 자료 생성, 국고채 참고 자료·한국 시장 자료 수신 중 하나라도 실패하면 실행을 실패로 끝냅니다

실패한 날에는 직전 공개본이 그대로 남고, 페이지 첫 화면에 실패 배너와 마지막 성공 시각이 나옵니다. 그래프 자료만 실패한 날에는 직전 그래프가 남고 "그래프는 그 날짜 기준"이라고 표시합니다. 예정된 실행이 아예 빠진 경우에도 배너를 띄웁니다. 수신에 실패한 시리즈가 3개 이상이면(캐시로 대신한 것 포함) 그날은 기록하지 않습니다 — 오래된 캐시를 오늘 결과로 내보내지 않기 위해서입니다.

## 그래프

페이지의 **금리의 구조**(최근 5년, 주간)와 **규칙 카드마다 작은 추이**(최근 3년)를 그립니다.

| 그래프 | 그리는 것 |
|---|---|
| 미 10년 금리 분해 | 명목 10년 · 10년 실질 · 10년 BEI |
| 기간 프리미엄과 10년−2년 | Kim-Wright 10년 기간 프리미엄 · 10년−2년 |
| 국고채 금리 · 국고채 장단기 금리차 | 참고 절의 국고 3·10·30년 금리와 10년−3년·30년−10년 금리차(글이 올라온 날 기준, 2026-09-03부터) |
| 규칙 카드 10개 | 그 규칙이 실제로 비교하는 양과 임계값 점선 (예: NDFI 전년비와 10%, 기간 프리미엄 3개월 변화와 −0.25%p, SOFR 3개월 변화와 +0.25%p) |

- **카드 값과 같은 계산입니다.** [`scripts/render_charts.py`](scripts/render_charts.py)가 표본 날짜마다 원자료를 그 날까지 자르고 규칙 점검과 같은 함수로 계산하므로, 그래프의 마지막 점이 카드에 적힌 값과 같습니다(테스트가 강제).
- 신용 스프레드 카드는 재배포 제한 자료라 그래프가 없습니다.
- 그래프마다 밑에 출처 줄이 붙습니다 — FRED 그래프는 FRED 시리즈 페이지가 적은 출처와 FRED 경유를, 국고채 그래프는 채널 이름과 금리 기준을 적고, 계산한 선이면 이 저장소가 계산했다는 표시를 붙입니다.
- 그래프는 외부 라이브러리 없이 [`site/charts.js`](site/charts.js)로 그립니다. 마우스·손가락·키보드(←/→)로 날짜별 값을 보고, "표로 보기"로 모든 값을 표로 볼 수 있습니다.

금융 단말기의 문법을 빌린 한 장짜리 화면입니다(2026-10-08 개편).

- **국면 모니터** — 규칙 11개를 표 하나에 모읍니다: 주제 · 규칙 · 최근 값 · 자료일 · 작은 추이선 · 판정. 규칙 이름을 누르면 그 주제 화면으로 갑니다.
- **명령줄과 번호 키** — 맨 위 명령줄에 화면 이름(일부만 쳐도 됩니다)이나 번호를 치고 Enter. 입력 칸 밖에서는 숫자 키 1~7로 화면을 바꾸고 `/`로 명령줄에 갑니다.
- **시세 띠** — 주요 수치가 한 줄로 흐릅니다. 마우스를 올리거나 초점을 두면 멈춥니다.
- **움직임 버튼** — 시세 띠, 값이 들어오는 깜박임, 그래프 선이 그려지는 움직임을 켜고 끕니다. 기기가 '움직임 줄이기'로 설정돼 있으면 꺼진 채로 시작하고, 고른 값은 그 브라우저에 기억됩니다.
- **글꼴만 바깥에서 받습니다.** IBM Plex Sans KR · IBM Plex Mono를 Google Fonts에서 불러오므로 페이지를 열면 그 서버로 요청이 나갑니다. 스크립트는 저장소의 것만 씁니다.

## 참고: 한국 국고채 금리

페이지의 **한국 국고채** 절(꼬리표 '채널 자료 · 규칙 판정 제외')은 위 규칙 점검과 성격이 다릅니다(2026-10-08 추가).

- **공개 통계가 아닙니다.** KB증권 리서치본부 채권크레딧팀이 텔레그램 공개 채널([t.me/jk_bond](https://t.me/jk_bond))에 평일 아침 올리는 '채권시장 일일동향' 글에서 국고채 3·5·10·30년 금리와 전일 대비 숫자만 옮깁니다(금리 기준은 그 글에 적힌 민평3사 — 민간 채권평가사 세 곳 평균). 글의 해설, 미국·크레딧·환율 구역, 글에 있던 글자는 옮기지 않습니다. 이 저장소는 KB증권·채권평가사와 관계가 없고, 채널 운영자나 금리 산출처가 요청하면 이 절을 내립니다.
- **규칙 판정에 쓰지 않습니다.** [`scripts/ktb_fetch.py`](scripts/ktb_fetch.py)는 판정 코드와 떨어져 있고, 판정·공개본·그래프 스크립트는 `data/ktb.json`을 읽지 않습니다(공개 전 검사만 모든 파일을 훑습니다).
- 날짜는 글이 올라온 날(한국 시간)이고, 글이 아침에 올라오므로 값은 직전 영업일 금리입니다. 장단기 금리차(10년−3년, 30년−10년)는 이 저장소가 그 금리로 계산합니다. 이 형식의 글은 2026-09-03부터 있어 그 전 자료는 없습니다.
- 예약 실행 한 번에 검색 결과 한 쪽만 요청합니다(처음 채울 때만 여러 쪽). 자동 갱신이 글보다 먼저 돌면 하루 늦게 반영됩니다.
- **형식이 바뀌면 닫힌 쪽으로 실패합니다.** 구역 머리글이 다르거나, 네 만기나 스프레드 줄 중 못 읽은 것이 있거나, 금리가 범위를 벗어나거나, 금리와 글에 적힌 스프레드가 맞지 않으면 그 글은 버립니다. 가장 최근 글을 읽지 못한 날은 실행을 실패로 끝내고, 페이지는 직전에 읽은 값과 그 날짜를 보여 줍니다. 글의 제목 줄이 바뀌어 알아보지 못하는 경우는 '새 글 없음'과 구분되지 않으므로, 마지막으로 읽은 글이 12일 넘게 묵으면 실패로 끝냅니다. 저장 파일이 깨져 있으면 덮어쓰지 않고 실패로 끝냅니다. 페이지에 나가는 문구는 코드에 정해 둔 것뿐입니다(테스트가 강제).

## 한국 시장 학습 화면

`한국 시장` 아래에 **금리·커브 / 신용·단기자금 / 수급·입찰**을 제공합니다. 기존 11개 규칙과 별개인 참고 자료입니다.

- **금리·커브**: 한국 3·10년, 미국 10년, 한국 10년−3년, 한국−미국 10년 금리차.
- **신용·단기자금**: 회사채 AA− 3년−국고채 3년, CD·CP 91일, CP−CD 금리차.
- **수급·입찰**: 외국인 3·10년 국채선물 당일·최근 5·20관측일 누적 순매수(계약수, 스프레드 거래 포함), 월별 국고채 입찰 일정과 최근 일반 국고채 경쟁입찰 결과(입찰금액·응찰률·가중평균 낙찰금리).

[`scripts/korea_market.py`](scripts/korea_market.py)가 공개 다운로드를 읽어 `data/korea.json`을 만들고 기존 아침 갱신에 함께 실행됩니다. API 키가 필요 없습니다. 발행공고 PDF는 `pypdf`로 읽으며, Actions에서 `requirements.txt`의 고정 버전을 자동 설치합니다. 나머지 수집·계산은 Python 표준 라이브러리를 사용합니다.

| 제공처 | 받는 자료 | 접근 방법 |
|---|---|---|
| [한국은행 금융·경제 스냅샷](https://snapshot.bok.or.kr/dashboard/A) | 금융투자협회·ECOS·미국 재무부 금리 | 공식 차트 엑셀 다운로드 3개(851·852·857) |
| [국채시장 투자자별 거래동향](https://ktb.mofe.go.kr/invstrDelngTrend.do) / 한국거래소 | 외국인 국채선물 순매수 | 해당 화면의 공개 조회, 3·10년 각 최근 100일 범위 |
| [공식 국채시장](https://ktb.mofe.go.kr/mnbyIsuCldr.do) | 월별 입찰 일정·경쟁입찰 결과 | 공개 일정과 최근 결과 공고(최대 8건)에서 숫자·날짜만 추출 |

한국은행 스냅샷 자료는 [이용지침](https://snapshot.bok.or.kr/guideline)에 따라 출처를 명시한 비상업적 학습 목적으로 이용합니다. 데이터는 코드의 MIT 라이선스 대상이 아닙니다. 친구의 비공개 사이트나 개인 파일은 수집·게시하지 않습니다.

**계산과 날짜**

- 금리 변화는 1·5·20 **유효 관측일** 전 대비 bp입니다(달력일이나 모든 시장의 공통 영업일을 뜻하지 않음). 비교 시작일은 변화 칸에 표시됩니다.
- 금리차는 날짜 교집합에서만 계산하며 결측을 전일 값으로 메우지 않습니다. 한미 같은 날짜 값도 시장 마감 시각은 다릅니다.
- 1년 분포는 마지막 관측일 기준 365일입니다. 200개 이상·300일 이상 이력이 있을 때만 계산합니다. 범위 위치=(현재−최저)/(최고−최저), 백분위=(현재보다 낮은 관측수+동률의 절반)/관측수. 모든 값이 같으면 범위 위치는 표시하지 않습니다.
- 국고채 최종호가와 기존 KB 채널의 민평3사 금리는 평가 기준·자료일이 달라 이어 붙이지 않습니다. 선물 계약수도 3·10년물을 단순 합산하지 않습니다.
- 입찰 예정액은 한국은행 발행공고의 경쟁입찰 금액을 날짜·만기에 맞춰 표시합니다. 결과가 나오면 결과 공고의 입찰금액을 우선합니다. 금액 링크는 해당 원문으로 연결되며, 확인되지 않은 예정액은 0으로 채우지 않고 발행공고 목록을 연결합니다. 일반 국고채 경쟁입찰만 추출하고 교환·모집·물가채 결과는 포함하지 않습니다.

**실패 처리**: 제목·단위·빈도 변경, 중복·미래 날짜, 범위 밖 수치, 선물 순매수 합계 불일치, 응찰률 산술 불일치 등을 거부합니다. 여덟 자료 묶음은 각각 마지막 성공 자료를 보존하며 수신 실패 상태·확인 시각을 노출합니다. 하나라도 실패하면 종료코드 1로 Actions 알림에 반영합니다. 공고 원문·담당자 정보·원격 HTML은 공개본에 넣지 않습니다.

## 공개 범위와 안전장치

- **원자료와 공개본을 나눴습니다.** 원자료 캐시와 원본 계산 결과는 커밋·배포하지 않는 작업 폴더에만 두고, 공개본은 허용 목록에 있는 값만 옮겨 만듭니다. 공개 문구를 정해 두지 않은 새 규칙이 원본에 생기면 공개본 만들기가 실패합니다.
- **공개 전 검사**([`scripts/check_blind.py`](scripts/check_blind.py)) — 개인정보·로컬 경로·토큰 같은 검사어가 작업 트리와 **과거 커밋 전체**(지운 파일, 커밋 작성자 정보 포함)에 하나라도 있으면 멈춥니다. 검사어 목록 자체는 공개하지 않고(로컬 파일·GitHub Secret), 인코딩을 바꾼 우회(전각 문자, HTML·JSON 이스케이프, CP949·UTF-16)도 찾습니다. 읽을 수 없는 파일은 통과시키지 않습니다.
  - push 전 로컬 훅(`.githooks/pre-push`, `git config core.hooksPath .githooks`로 켬)에서 걸리면 push가 멈춥니다.
  - GitHub Actions에서는 매 실행 처음과 봇 커밋 직전에 돌고, 걸리면 봇 커밋과 페이지 배포를 멈춥니다(이 검사는 push된 뒤에 돕니다).
- **그래프 자료도 같은 허용 목록으로** 만듭니다. 재배포가 제한된 지수의 원값은 어느 날짜 것도 싣지 않고(S&P500은 원값을 되살릴 수 없는 60영업일 상관만), 문구는 코드에 정해 둔 것만 나갑니다.
- **출처 표기** — 공개본(`data/public.json`)에는 시리즈마다 FRED 권장 인용(원 출처, 영문 제목 [ID], retrieved from FRED; 시리즈 주소, 기준일)을, 페이지에는 시리즈별 FRED 링크·마지막 관측일·오래된 자료 표시와 그래프별 출처 줄을 싣습니다.
- **SOFR 고지** — 뉴욕 연은 이용약관(2023-06-09 개정)은 SOFR 같은 참조금리 자료를 쓰거나 배포할 때 정해진 고지·면책 문구를 요구합니다(2026-09-30 원문 확인). 그 문구와 DTCC 문장(원문 그대로), 뉴욕 연은 기본 출처 표기(© 연도)는 꼬리말과 SOFR 카드(그래프 아래)에, "SOFR 3개월 변화는 이 저장소가 계산한 값"이라는 표시(한·영)와 관계없음 고지는 SOFR 카드에 싣습니다. JSON에도 같은 문구가 들어갑니다(`public.json`·`charts.json`의 `attribution`, SOFR 규칙·그래프의 `notices`). 이 사이트는 뉴욕 연은·세인트루이스 연은(FRED)과 관계가 없습니다(영문 고지는 꼬리말). 2026-09-30 이전 커밋의 기록 파일에는 이 고지가 없었고, 지금 저장소의 기록 파일은 값은 그대로 두고 고지·인용만 채워 다시 저장했습니다.
- **계산값 표시** — 전년비·3개월 변화·비율·상관처럼 이 저장소가 계산한 값은 카드에 '계산값'으로, 그래프는 출처 줄에 '이 저장소가 계산한 값'으로 표시합니다.

## 한계

- **임계값은 추정치입니다.** 대부분은 개인 조사 보고서의 추정 수치이고, 기간 프리미엄·SOFR의 0.25%p와 지준 재확대 조건(3개월 +0.3%p, 근원 PCE 2%)은 보고서에 수치가 없어 구현 때 정한 제안값입니다. 어느 쪽도 적중률로 검증한 기준이 아닙니다. 규칙은 첫 실행 직전까지 다듬었고(판정 경계·3값 논리·계단 제외), 바뀐 내용은 커밋 기록에 남아 있습니다.
- **발표 시차** — GDP 같은 분기·월간 지표는 수 주에서 수 개월 늦게 반영됩니다. 페이지의 자료 기준일을 함께 봐야 합니다.
- **개정치** — FRED 값은 나중에 고쳐집니다. 과거 날짜를 다시 계산한 결과는 작업 폴더(비공개)에만 남기고, 공개본(`data/public.json`)과 `data/history/`는 되돌리지 않습니다.
- **결측** — 근원 CPI는 2025-10이 비어 있어, 그 달이 기준이 되는 12개월 뒤 전년비는 '산출 불가'로 둡니다.
- GitHub Actions 예약 실행은 늦게 돕니다. 지금까지 일곱 번은 모두 예약 시각보다 3~4시간 뒤(한국 시간 오전 10~11시대)에 끝났고, 페이지의 '예정된 갱신이 반영되지 않았다' 배너는 5시간까지 기다립니다.
- **국고채 참고 절은 남의 채널 글에 기대고 있습니다.** 글 형식이 바뀌거나 채널 미리보기가 닫히면 그날부터 갱신이 멈춥니다(실패 알림과 페이지의 날짜 표시로 드러납니다).
